==================================================
CURRENT PRODUCT STATUS
==================================================

Cogniv is a personal learning tracker built around
YouTube courses and playlists.

Current working flow:

YouTube Playlist
        ↓
Import into Cogniv
        ↓
Course
        ↓
Lessons
        ↓
YouTube Player / External YouTube
        ↓
Chrome Extension tracks progress
        ↓
Backend stores progress
        ↓
Cogniv synchronizes progress
        ↓
Course overview displays progress

==================================================
DEVELOPMENT RULES
==================================================

1. Do not rewrite working code unnecessarily.

2. Make one logical change at a time.

3. Test after every significant change.

4. Commit working changes to Git.

5. Never commit:
   - node_modules
   - Python virtual environments
   - database secrets
   - API keys
   - .env files
   - build output
   - browser extension generated files

6. Never use hardcoded production secrets.

7. Keep backend and frontend responsibilities separate.

8. Keep extension logic separate from frontend logic.

9. Do not add features just because they are possible.

10. Prioritize reliability over feature count.
