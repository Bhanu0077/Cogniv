# 🧠 Cogniv

### Learn. Track. Continue. Master.

Cogniv is a learning progress platform that connects **YouTube learning activity** with a personal course dashboard.

Instead of manually marking videos as watched, Cogniv can detect learning activity on YouTube, connect videos to courses, store progress, and display the latest learning status inside the Cogniv dashboard.

> **Turn YouTube playlists into measurable learning progress.**

---

## ✨ What is Cogniv?

Cogniv is designed around a simple problem:

> You watch educational videos on YouTube, but your learning progress is scattered across playlists, browser history, and memory.
